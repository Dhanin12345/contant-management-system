# Contact Management System

A desktop and console-based Contact Management System built with Python (Tkinter + SQLite) and Java.

## Features
- **Tkinter Desktop GUI** (`main.py`): Add, update, delete, view, and manage contacts with SQLite database storage (`Contact.db`).
- **Python Console Version** (`contact system.2.py`): Text-based interactive contact manager with validation.
- **Java Console Version** (`ContactApp.java`): Object-oriented contact manager in Java.

## How to Run

### 1. Python Tkinter GUI Application
```bash
python main.py
```

### 2. Python Console Application
```bash
python "contact system.2.py"
```

### 3. Java Console Application
```bash
javac ContactApp.java
java ContactApp
```
